ชุดโครงการชุมชนที่สร้างขึ้นบน XPENGagent

:::note
ต้องการเพิ่มโครงการที่เกี่ยวข้องกับ XPENGagent ของคุณลงในรายการนี้หรือไม่ ส่งพีอาร์.
:::

คุณยังสามารถลองดู [awesome-xpengagent](https://github.com/awesome-xpengagent/awesome-xpengagent) และ [xpengagent.cafe](https://xpengagent.cafe) ซึ่งเป็นชุมชนที่รวบรวมระบบนิเวศและชุมชนไว้ด้วยกัน
