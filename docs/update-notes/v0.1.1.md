## 变更内容

### 域名替换
将项目所有引用 `xpengagent.ai` 的域名替换为 `xpengagent.cc.cd`，采用**方案 C（通配子域名）**，完整保留子域名结构。共涉及 **504 个文件，4587 处引用**，替换后零残留。

| 旧域名 | 新域名 | 说明 |
|--------|--------|------|
| `xpengagent.ai` | `xpengagent.cc.cd` | 主站 |
| `console.xpengagent.ai` | `console.xpengagent.cc.cd` | 控制台 |
| `api.xpengagent.ai` | `api.xpengagent.cc.cd` | API |
| `app.xpengagent.ai` | `app.xpengagent.cc.cd` | 应用 |
| `docs.xpengagent.ai` | `docs.xpengagent.cc.cd` | 文档 |
| `stats.xpengagent.ai` | `stats.xpengagent.cc.cd` | 统计 |
| `enterprise.xpengagent.ai` | `enterprise.xpengagent.cc.cd` | 企业版 |
| `dev.xpengagent.ai` | `dev.xpengagent.cc.cd` | 开发环境 |

### 影响范围
- **Provider HTTP-Referer**：所有 AI Provider 请求头中的 `HTTP-Referer` 同步更新为新域名
- **安装脚本**：`curl -fsSL https://xpengagent.cc.cd/install | bash` 有效
- **Schema URL**：`$schema` 字段指向 `https://xpengagent.cc.cd/config.json`
- **CI/CD**：GitHub Workflows 中的 bot 邮箱更新为 `bot@xpengagent.cc.cd`
- **认证域名检测**：`location.hostname.includes("xpengagent.cc.cd")` 生效
