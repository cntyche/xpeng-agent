## 变更内容

### 1. 安装脚本优化：PATH 自动配置

安装完成后 `/root/.local/bin` 未在 PATH 中，用户需手动 export。现改为自动写入 shell rc 文件 + 当前会话生效。

**改动文件**：
- `releases/install.sh`
- `releases/0.0.0-dev-20260624-v2/install.sh`
- `packages/xpengagent/script/install.sh`

**变更**：`warn` → `echo >> shell_rc` + `export PATH`

### 2. 构建脚本改进：相对路径修正

`package-release.sh` 中 `OUTPUT_DIR` 使用相对路径时，从非项目目录调用会失败。改为自动转绝对路径。

**改动文件**：`packages/xpengagent/script/package-release.sh`

### 3. 新增热门提供商

| 提供商 | ID | 密钥方式 | 模型 |
|:---|:---|:---|:---|
| **XPENG Free** | `xpengagent-free` | 内嵌密钥，开箱即用 | DeepSeek V3/R1, Qwen Plus/Turbo, GLM-4 Flash, Hunyuan Turbo |
| **幻城网安** | `huocheng-websecurity` | 用户自行填入 | DeepSeek V3/R1, Qwen Plus/Turbo, GLM-4 Flash, Hunyuan Turbo |
| **Agnes** | `agnes` | `AGNES_API_KEY` 环境变量或 API key | Agnes 2.0 Flash |

**新增文件**：
- `packages/core/src/plugin/provider/xpengagent-free.ts`
- `packages/core/src/plugin/provider/huocheng-websecurity.ts`
- `packages/core/src/plugin/provider/agnes.ts`

**改动文件**（15 files）：
- Core: `plugin/provider.ts`、`provider.ts`（well-known IDs）
- Runtime: `provider/provider.ts`（database 注册 + custom loader + mergeProvider 修复）
- TUI: `dialog-provider.tsx`（Popular 优先级 + 描述）、`dialog-model.tsx`（Free 标识 + 排序）
- App: `use-providers.ts`、`dialog-select-provider.tsx`、`dialog-select-model.tsx`、`dialog-select-model-unpaid.tsx`、`settings-v2/providers.tsx`
- CLI: `providers.ts`、`footer.command.tsx`

### 4. TUI Logo 替换

将启动界面 "open│code" 标识替换为 "XPENG│AGENT"。

**改动文件**：`packages/tui/src/logo.ts`
